# 자료구조와 알고리즘

## 알고리즘

: 어떤한 목적을 이루기 위해 필요한 일련의 연산 절차

자료구조가 데이터를 효율적으로 저장하고 관리하기 위한 방법 

알고리즘은 어떤 목적을 이루기 위한 효율적인 연산 방법

## 자료구조

: 이름 그대로 어떠한 구조로 데이터를 다룰지에 한 정의로, 데이터를 효율적으로 저장하고 접근하기 위한 방식

# 시간 복잡도와 공간 복잡도

개발자는 프로그램을 만드는 과정에서 소스 코드를 통해 다양한 데이터를 다루고(자료구조), 데이터를 활용해 특정 목적을 이루기 위한 연산(알고리즘)을 구현한다.

⇒ 자료구조와 알고리즘을 고려하며 작성한 코드는 품질⬆️

## 시간 복잡도(time complexity)

: 입력의 크기에 따른 프로그램 실행 시간의 관계

- 프로그램의 실행 시간과 입력의 크기는 밀접한 관계.
    
    <aside>
    
    **ex)**
    
    - 서로 다른 N개의 데이터가 있을 때, 앞에서부터 차례대로 하나씩 검사하여 특정 데이터를 찾는 프로그램
        - 데이터가 하나(N=1)라면 프로그램의 실행 시간이 길지 않다.
        - 데이터가 100개(N=100)라면 일반적으로 조금 더 오랜 시간이 소요될 것이다.
        - N이 10000이라면 실행 시간이 평균적으로 훨씬 더 오래 걸릴 것이다.
        
        ![image.png](attachment:76d07be9-47a3-4b7d-826d-76c03fbf8a18:image.png)
        
        - 실행 시간은 연산 횟수에 따라 비례한다고 간주
        
        ⇒ 시간 복잡도는 입력의 크기에 따른 프로그램 실행 시간이라고 할 수도 있고, 입력 크기에 따른 연산 횟수라고 할 수도 있다.
        
    </aside>
    

```python
for _ in range(n):        # 입력으로 주어진 값은 n; n회 반복하며
	for _ in range(n):      # 각각의 반복을 n회씩 반복하며
		1 + 1                 # 한 번씩 연산

'''
n^2번
'''
	
for _ in range(3 * n):    # 입력으로 주어진 값은 n; 3n회 반복하며
		1 + 1                 # 한 번씩 연산
		
'''
3n번
'''		

1+1                       # 한 번씩 연산
1+1                       # 한 번씩 연산

'''
2번
'''
```

- 운 좋게 단번에 원하는 데이터를 찾아낼 수도 있고
- 데이터를 찾는 모든 연산을 끝내야만 원하는 데이터를 찾아낼 수도 있다.

## 빅 오 표기법(big O notation)

: 함수의 점근적 상한을 표기하는 방법

- 입력의 크기 n에 대한 빅 오 표기법은 **O(상한(n))** 형태로 표현 → n이 무한대로 커지더라도 **실행 시간이 이 이상은 커지지 않음**을 의미
- 표기법
    
    $$
    \forall x \geq x_0 \text{ 에 대해 } f(x) \leq cg(x) \text{를 만족하는 양의 상수 } c \text{와 } x_0 \text{가 존재할 경우,}\\ O(g(x)) = f(x) \text{이다.}
    $$
    

<aside>

ex) O(n²) → 실행 시간의 증가율이 n²보다는 작다

</aside>

> 참고 — 다른 표기법
> 
> - **빅 세타 Θ(n²)** : 실행 시간 증가율 = n² (평균)
>     
>     $$
>     f(x) = O(g(x)) \text{와 } f(x) = \Omega(g(x)) \text{가 모두 성립할 경우,}\\ \theta(g(x)) = f(x) \text{이다.}
>     $$
>     
> - **빅 오메가 Ω(n²)** : 실행 시간 증가율 ≥ n² (하한)
>     
>     $$
>     \forall x \geq x_0 \text{ 에 대해 } f(x) \geq cg(x) \text{를 만족하는 양의 상수 } c \text{와 } x_0 \text{가 존재할 경우,}\\ \Omega(g(x)) = f(x) \text{이다.}
>     $$
>     
> - 코드 성능 판단엔 **빅 오가 가장 대중적**
- 입력값 n에 대한 실행 시간의 점근적 상한을 수식으로 표현할 때는 최고차항으 차수만 고려한다.

### 대표 시간 복잡도

| 표기 | 의미 |
| --- | --- |
| O(1) | 상수 시간 |
| O(log n) | 로그 시간 |
| O(n) | 선형 시간 |
| O(n log n) | 선형 로그 시간 |
| O(n²) | 이차 시간 |
- 정렬 알고리즘별 시간복잡도

## 공간 복잡도(space complexity)

: 프로그램이 실행되었을 때 필요한 메모리 자원의 양

- 시간 복잡도가 입력에 따른 실행 시간의 척도라면, 
공간 복잡도는 입력에 따른 메모리 사용량의 척도
- 빅오 표기법으로 표현하면 **입력에 따라 필요한 메모리 자원의 양에 대한 점근적 상한**을 표현
