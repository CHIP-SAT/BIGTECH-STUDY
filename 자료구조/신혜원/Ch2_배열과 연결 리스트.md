## 정적 배열과 동적 배열

### 정적 배열(static array)

: 프로그램을 실행하기 전에 크기가 고정되어 있는 배열

- 배열의 크기는 원칙적으로 프로그램 실행 도중에 바꾸지 못함
- ex) 5개의 원소를 할당하도록 정적 배열을 선언함 ⇒ 실행 도중에는 6개 이상의 원소를 할당X

### 동적 배열(dynamic array)

: 실행 과정에서 크기가 변할 수 있는 배열

- 포함된 요소의 개수가 동적으로 변할 수 있는 특성 ⇒ 프로그램 실행하기 전에 배열의 크기를 알기 어려운 경우, 유연하게 요소의 개수를 조정해야 하는 경우에 사용할 수 있다.
- **= 벡터(vector)**

## 연결 리스트(linked list)

: 노드의 모음으로 구성된 자료구조

### 노드(node)

: 그림과 같이 1️⃣ 저장하고자 하는 데이터(들)와 2️⃣다음 노드의 위치(메모리 상의 주소) 정보를 포함하는 연결 리스트의 구성 단위

![image.png](attachment:71a7efb2-a51e-44b3-9f90-6d7db0345244:image.png)

### 헤드(head)

: 첫 번째 노드

### 꼬리(tail)

: 마지막 노드

- 연결 리스트를 구성하는 모든 노드는 반드시 메모리 내에 순차적으로 저장되어 있을 필요가 없다.
- ⇒ **연속적으로 구성되어 있는 데이터를 불연속적으로 저장 할 때 유용**

![image.png](attachment:3d6dd92d-d3f3-44b2-9d22-df141b962f36:image.png)

- 연결 리스트에서 특정 요소에 접근할 때는 앞에서부터 순차적으로 접근할 수밖에 없기 때문에 O(n)이 소요된다.

![image.png](attachment:046a123a-4ad2-46dc-bfbb-2cf96f0abf01:image.png)

- 연결 리스트는 배열에 비해 추가 및 삭제 연산에서 강점이 있다.
- 연결 리스트는 중간에 요소를 추가하거나 삭제하는 연산에서 재정렬이 불필요하기 때문에
- ⇒ 새로운 노드 삽입 or 삭제할 위치가 주어지면 O(1)이 소요

![image.png](attachment:76015fdf-3ec4-4952-8ba7-02c5d3eee5a6:image.png)

### 싱글 연결 리스트(singly linked list)

- 연결 리스트에는 기본적으로 노드 내에 다음 노드의 위치 정보가 저장되어, 한 쪽 방향으로 꼬리에 꼬리를 무는 형태
- 다음 노드의 위치만 알 수 있음(= 이전 노드의 위치는 알기 어려움)
- 단방향으로만 탐색 가능

### 이중 연결 리스트(doubly linked list)

- 싱글 연결 리스트를 보완하기 위한 연결 리스트의 변형
- 다음 노드의 위치 정보뿐만 아니라 이전 노드의 위치 정보도 포함하고 있는 연결 리스트
- 양방향 탐색 가능
- 한 노드에 2개의 위치 정보(메모리 주소)를 저장해야 하므로 저장 공간 더 필요하다는 단점이 있음

![image.png](attachment:e147da1f-1751-471c-a365-8a3333080435:image.png)

### 환형 연결 리스트(원형 연결 리스트)(circular linked list)

- 꼬리 노드(마지막)가 헤드 노드(첫 번째)를 가리켜 노드들이 원형으로 구성된 연결 리스트

![image.png](attachment:21a2134d-eba8-4f2d-9d0f-fd29ec28c4dd:image.png)

#### 이중 원형 연결 리스트

- 헤드 노드의 이전 노드가 꼬리 노드를 가리키고, 헤드 노드의 다음 노드가 헤드 노드를 가리키는 연결 리스트
- 모든 노드 데이터를 여러 차례 순회해야 할 때 유용하게 활용 가능
